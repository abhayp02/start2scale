# Start2Scale

Start2Scale is a government-startup innovation procurement platform.

## Phase 0 setup

1. Copy `.env.example` to `.env` and provide your MongoDB Atlas connection string.
2. Install dependencies with `npm install` in both `backend` and `frontend`.
3. Start the backend with `npm run dev` from `backend`.
4. Start the frontend with `npm run dev` from `frontend`.

The backend health check is available at `GET http://localhost:5000/api/health`.
